# Portfolio de Data Analyst



Profesora de matemáticas en reconversión hacia el análisis de datos, combinando mi formación matemática con experiencia real de negocio en la empresa familiar de mecánica automotriz (inventario, stock, ventas y facturación).



Este repositorio reúne mis proyectos de formación en Google Sheets, SQL y Power BI, aplicados a casos de negocio reales: desde el análisis del taller mecánico familiar hasta un proyecto integrador con datos públicos de Argentina.
